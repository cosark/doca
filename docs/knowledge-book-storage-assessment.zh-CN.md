# 知识册存储评估

[English](knowledge-book-storage-assessment.md)

2026-10-12 完成评估，2026-10-13 按用户明确批准的完整方案完成实现与隔离验收。复用宿主私有 local/S3 对象存储，正文按同册哈希共享、原 JSON 无损还原；未部署或迁移生产知识册。

## 当前容量与失败原因

`book_size_limit` 对应多个 413 错误：来源规模、组合来源、模型上下文、单次响应、格式修复上下文和发布成果规模；没有“整册十几 KB”的统一阈值。发布前现有成果 JSON 最多 10,000,000 字符。单来源组最多 120,000 字符，人工材料绑定最多 60,000 字符；这些均是字符数。2026-10-14 按已批准的分批执行方案移除节点组合来源的旧上限。模型还受其配置的输入上下文及单次 `min(maxOutput, 32,000)` Token 输出限制，单次响应有 500,000 字符保护。第 1 版生成协议最多 1,000 条判断、200 页，每页 200 段，每段 12,000 字符。详细验收也按批次处理，全册验收只接收宿主统计、目录及层次化汇总的有界批次结论，不再接收全文。单次请求和目录元数据仍须适配模型上下文，发布及协议限制保留，不能承诺无限容量。

新实现会把写作上下文超限和响应截断转为更小的完整判断/段落请求，不要求减少正文深度。不改历史来源、工作流配置、节点 JSON 或成果格式。断点恢复复用已完成节点；失败节点内未完成的批次需重新生成。

## 数据库为何膨胀

| 存储位置 | 内容 | 重复来源 |
| --- | --- | --- |
| knowledge_book_node_runs.output | 每个节点的完整 evidence/claims/pages/checks | 汇总、组织、验收、发布各保留上游内容 |
| knowledge_book_runs.artifact | 候选/完成成果及溯源图 | 与节点输出及发布成果重叠 |
| knowledge_book_releases.artifact | 不可变发布成果 | 通常与运行成果再次重叠 |
| 成果 provenance.nodes | 段落正文作为 label，证据又包含 label/text | 同一成果内也重复正文 |
| 来源及配置历史 | 人工材料、规则、来源版本 | 多个历史版本保留配置，不能擅自清理 |

原始来源正文不另外归档；节点保留准确引用的摘录。数值日志位于 audit_events 的短 action 中，通常不是主要空间来源。失败和重试历史必须保留，不能通过清库解决。

合成的 6 章、80,040 字符示例，使用当前 7 节点流程和真实 createBookProvenance 函数计算：

| 项目 | UTF-8 JSON 字节 |
| --- | ---: |
| 正文字符串本身 | 239,040 |
| 汇总/组织/验收/发布输出（每份） | 250,903 |
| 运行成果（包含溯源） | 559,986 |
| 发布成果 | 559,986 |
| 全部节点输出＋运行成果＋发布成果 | 2,129,658 |

约为正文 UTF-8 字节的 8.9 倍；未包括来源历史、数据库页、索引、WAL 和备份。它是重复内容的可复现演示，不是生产数据库大小统计。合成文本大量重复，其 gzip 结果不适合预测真实压缩率。原始数据记录在 `docs/verification/knowledge-book-reliability-2026-10-12/storage-size.json`。

## 已实现的存储与转换

数据库保留工作流、状态、租约/心跳、待办、权限清单、摘要、对象索引及持久化上传/清理记录。节点输出和运行/发布成果置于宿主私有对象存储；大字符串以原始 JSON 转义字节按同册内容哈希共享，外部第 1 版成果和溯源图保持原样。索引分片与正文 gzip 后校验长度和 SHA-256，同一运行与发布可共享根清单。

复用宿主既有 local/S3 配置及不可变上传、回读能力，不新增模块凭据或公开正文地址。事务外完成上传校验，事务内复验当前运行租约并提交引用和完成事实。缺失或损坏对象明确失败并保留引用；不可变字节缓存与当前权限检查分离。轮询使用数据库摘要，正文按需读取。回收站保留内容，永久删除释放引用后清理不可达对象；没有新增历史 TTL。

完整转换方案已明确获批。当前代际是 `doca-2026-10-12-book-payload-storage-v1`；从已发布 0.1.22 的 `doca-2026-10-09-history-storage-v1` 只允许显式停机转换全部原 JSON。正常启动不迁移、不双读；未知格式、待审结构差异与运行中任务阻止转换。回退恢复升级后的新成果并保留云对象和清单。具体字段和恢复步骤见[实施方案](knowledge-book-payload-storage-plan.zh-CN.md)。

实际旧版镜像生成的 SQLite、PostgreSQL 17/18 样本，每组 20 份正文均逐字节升级与回退。3,698,834 字节 SQL 正文变为 7,170 字节引用和约 403–404 KB 的元数据 JSON，已注册压缩对象约 95 KB。元数据数字不等同数据库物理文件；重复合成文本的压缩率不能代表生产收益。详情见[验证及运维](knowledge-book-storage-verification.zh-CN.md)。

成本包括对象请求延迟、网络故障、跨存储提交和持续清理。源配置与历史保留仍在 SQL，不能靠删除历史减少占用；实际备份、WAL 和存储费用仍须用代表性生产册单独测量。
