# Doca 0.2.11 — 编辑器修复与浏览器助手

[English](0.2.11.md)

Doca 接入正式 npm `@smartdoca/canvas` 0.5.15 与 `@smartdoca/sheet` 0.2.12。新建原生表格无需重新打开即可被完整框选。表格按已批准规则，在确认有效筛选条件或紧邻追加记录时持久化范围扩展；追加内容和范围扩展共用一次协作事务及撤销。打开、取消、清除条件、纯样式和原列范围外内容不扩展范围。

画布、表格、幻灯片的评论标注默认隐藏，随评论侧栏打开/关闭，移除独立眼睛按钮。画布便签重新打开用户卡片时正确获得宿主语言上下文。评论发送提示保持到刷新列表包含已提交评论。富文本和 Markdown 修改标题时保留适用的原格式。

浏览器助手每条新消息重新获取当前标签页，重试继续使用冻结材料；图片不可读时仍可读取正文。完整收录继续拒绝缺失图片，不提交不完整内容。选区工具栏重新获取登录状态，提供登录、重试和旧脚本刷新操作。移除插件快速记录界面；已写文档及服务端接口保留。升级后请更新插件并刷新已有网页。

编辑器公开 API、schema 1/6、baseline、epoch、checkpoint 和待确认正文更新格式不变。既有历史读取、工作表默认值、浏览器鉴权和 AI 待发送队列规则保持原状。相对 0.2.10 无新增格式适配、迁移、字段回填或数据库结构变化。回退保留后续正文、上一版部署、依赖和锁文件；前一 Sheet 包可读取保存的原生范围，但不会持久化其后隐式扩展。

继续遵循 [0.2.8 升级/恢复要求](0.2.8.zh-CN.md)与[数据库规范](../database-schema-evolution.zh-CN.md)，保留数据库、文件卷及部署主密钥，统一更新服务端、Web 和插件。验证仅使用隔离账号、文档及数据库。发布制品不等于部署生产站点。证据见[编辑器评论](../verification/editor-comments-2026-10-23.md)、[筛选范围](../verification/sheet-filter-range-2026-10-23.md)和[浏览器助手](../verification/browser-assistant-fixes-2026-10-23.md)。
