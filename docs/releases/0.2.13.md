# Doca 0.2.13 — Browser toolbar and large-image capture

[简体中文](0.2.13.zh-CN.md)

Browser extension 0.2.2 adds four persistent right-side icons: capture this page, capture selection, Doca assistant and settings. Drag the top handle vertically; its position survives reloads. Capture opens a rule/destination confirmation bubble. Settings opens a dedicated page for profile management and the backend address. Selecting text no longer shows another floating icon.

AI messages appear once across the conversation and pending list. Sending and accepted messages use conversation bubbles; waiting messages remain in the queue without waiting for an AI answer to disappear. Durable IndexedDB recovery copies, original message IDs, authorization boundaries and acceptance reconciliation keep their existing rules.

Under the owner-approved policy, newly captured static images over 4 MiB or 25 million pixels are compressed before upload to at most 4 MiB, a 4096-pixel longest edge and 16 million pixels. Source encoding, PNG/WebP alpha and EXIF display orientation are preserved. GIF, animated WebP and APNG are never flattened and fail explicitly above the existing animation limit. Stored and already-uploaded images are not reprocessed. Source reads are bounded to 64 MiB and static decoding to 100 million pixels; see [Browser assistant](../browser-assistant.md).

After updating Doca, download the extension again from Browser assistant settings, replace the unpacked folder and reload it in Chrome / Edge. Reload open webpages to show the new toolbar. Updating only the server does not update installed extensions.

There are no database structure, pending-queue format or editor SDK changes, and no migration, deletion or historical backfill. Preserve databases, assets and browser storage. Rollback follows the existing queue-disable contract without exporting IndexedDB into legacy localStorage. Compressed images remain supported image formats and are not restored or converted during rollback.

Focused tests, three real Chromium MV3 runs, 390px/200% layouts, alpha and EXIF checks are recorded in the [feature verification](../verification/browser-extension-dock-2026-10-23.md).

The full suite passed 3352 tests with 11 configured skips. Both native container gates, the public version/latest manifests and all three GitHub assets passed verification; see the [publication receipt](../verification/release-0.2.13.md).
