# Doca 0.1.31 — 画板、演示文稿与 AI 创作

[English](0.1.31.md)

本版锁定正式发布的 `@smartdoca/canvas` 0.5.2、`@smartdoca/slate` 0.4.22 和 `@smartdoca/slides` 0.3.0-alpha.3。画板修复连续中文输入，工具条随平移和缩放跟随元素；表格按换行文字、合并格和媒体撑高整行。临时 Canvas 0.5.0 包已从运行依赖中移除。

画板资源接入宿主上传、进度、取消和鉴权预览；相对文字选区与场景指针沿用原有已认证 presence 通道。演示文稿接入当前控制器的文字内边距和原生表格。

AI 助手支持完整 PPT 的生成与定向修改，以及流程图、思维导图、画布表格、手机／平板 UI 和可编辑矢量图案。工具及内置 skill 说明当前命令与准确单位，保护表格结构，递归删除思维主题后代，并返回最终行列坐标。删除旧画布／PPT 参数别名、元素猜测和像素／EMU 自动判断。独立验收改为流式消费响应，仍要求只读快照回读和有效验收记录。

工作区增加文档来源筛选与上传入口；修正原生选区引用给 AI、迟到聊天快照覆盖新消息、管理页在线状态的时序问题。电子表格 AI 仅修改颜色时保留原文字与公式。

## 升级与恢复

服务端与 Web 同步更新。保留数据库、资源文件、配置、原凭据主密钥、checkpoint 及待提交更新。核心数据库 DDL 与兼容代不变。画布继续使用 `aidcanvas-yjs` schema 1，不做文稿转换、历史字段补写、epoch 重写或自动迁移。Canvas 0.5.2 模型运行代码与已验收的 0.5.0 临时包一致，公开接口不变；修复位于编辑器运行层。

**此演示文稿版本仅支持新建文稿。** 用户已明确同意 revision 6（`eppt-yjs-v6`、文档 schema 2、protocol 1）。现有 revision-5 文稿和旧客户端明确拒绝；原 checkpoint、更新日志、epoch、历史和待提交消息 ID 保留，不自动转换。恢复时保留原部署及依赖锁定；旧编辑器不保证能读取后续新写入，回退前须保留这些数据。

已发布的 0.1.30 PostgreSQL 插件账号策略保持不变，插件业务数据库仍须与核心数据库分开。本次不发布 SDK，也不重置插件数据。
