# Doca 0.1.32 — 编辑器升级、权限状态与标题图标

[English](0.1.32.md)

画板便签、卡片和表格单元格的富文本支持输入 @ 选择用户，以及粘贴同源 Doca 文档地址后展示原生行内文档引用。宿主负责有权限的用户查询、用户卡片和文档标题；提及和引用通过已有协作提交、通知和引用索引处理。复制粘贴、原子删除、撤销重做、双页面同步和刷新保留稳定 UUID。

画板附件改接 `onAttachmentPreview`，普通编辑及只读、历史、回收站、审计界面均使用公共文件预览器和原有资源权限。图片保留资源回调，下载仍由宿主授权。

Slate 升级至正式发布的 0.4.23，采用 LeaferJS 思维导图工作区和预览；DOCX 样式补丁保持原内容。Canvas 包含 0.5.3 的预览与导航修复，并增加 0.5.4 原生行内扩展接口，已发布 npm 正式版本 `@smartdoca/canvas` 0.5.4。宿主锁定 npm 版本与完整性校验，不使用本地压缩包。

文档权限状态根据当前有效权限实时计算：仅自己可访问为红色“私有”，多人可访问为蓝色“协作”，面向登录用户或所有人开放为绿色“公开”。停用用户不计入协作人数，继承权限、知识库管理权限及显式阻止均参与判断。主页和文档左上角在标题后展示实色白字标签；文档列表使用独立“权限”列。富文本正文标题保持原样。窄屏顶部自动换行，保留标题和权限状态。

标题以 emoji 加空格开头时，列表、侧边树、置顶和搜索结果使用该 emoji 代替原类型图标，并隐藏标题中的重复前缀。创建和重命名支持常用图标选择、手写／粘贴完整 emoji、移除图标；仍按原生标题字符串保存，不回填或改写历史标题。保存失败会保留当前草稿以便重试。

## 升级与恢复

服务端和网页一起升级。所有者已同意现有导图采用新版显示默认值，也同意新增画板行内元数据不承诺旧客户端识别。打开、关闭现有导图或刷新预览不改写原始树，明确保存才提交原生字段。原有画板正文、历史读取器、checkpoint、epoch、待确认字节和消息 ID 原样保留。Canvas 仍为 `aidcanvas-yjs` schema 1，富文本仍为 schema 3；画板格式和行内元数据保持原有整字段 LWW 语义，不宣称逐字符格式 CRDT。

没有数据库结构变更、迁移、回填、旧格式适配或正文删除。保留 0.1.31、原包版本／补丁／锁文件、数据库、私有资源、配置和凭证主密钥。回退前保存后续写入，旧编辑器不保证识别新行内元数据或按新版样式显示导图。
