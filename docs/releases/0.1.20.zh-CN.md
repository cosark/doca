# Doca 0.1.20

[English](0.1.20.md)

本版修复搜索同步的生命周期和任务跟踪，并统一宿主导航与管理页面的插件图标。插件 SDK 保持 0.1.10。

## 改动

- 核心模块完成搜索来源注册后再启动同步；停止应用时，先结束正在执行的搜索任务，再释放来源，避免 `Search source is not registered` 错误。
- Meilisearch 已接受的任务在排队或处理期间持续跟踪，不再因本地五分钟时限放弃仍在执行的任务；停止应用仍会结束等待。
- 向量诊断只读取当前任务及其批次，避免将历史批次的额度错误归到新任务。
- 插件导航默认使用商店 PNG 图标，覆盖侧边栏、右上角、更多菜单与管理员入口；导航管理中明确设置的图标仍然生效。
- 商店卡片、已安装和待升级列表、插件详情、导航设置与扩展按钮共用图标组件。通过商店/npm 安装的插件在待启动或停用时也可读取图标；本地包和未知插件 ID 不触发商店查询。

## 验证与交付

发行验证附件记录全量检查、文档校验、镜像启动与停止验证、资源校验和及发布镜像摘要。

- GitHub 标签 `v0.1.20`，附 Web 资源、仅使用镜像的部署包及 SHA-256 校验文件。
- Docker `docker.io/smartdoca/doca:0.1.20` 与 `latest`，支持 Linux amd64、arm64。
- SDK 导出、插件声明、商店协议与安装记录维持现有格式。

## 部署与回退

数据库基线仍为 `doca-2026-10-09-history-storage-v1`。本版不新增数据库迁移、持久化数据转换或旧格式适配；已存在的严格基线校验与显式历史维护命令未修改。

0.1.19 部署更新镜像时，保留原数据库、文件、配置、Compose 项目名与 `DOCA_CREDENTIAL_MASTER_KEY`。更新后重建受影响的搜索索引，并确认 Meilisearch 任务成功；模型可用不能代替任务完成。更早基线遵守 [0.1.15 要求](0.1.15.zh-CN.md)。停止写入并备份数据后，可使用保留的旧镜像和发行制品回退。

在线拉取与离线镜像交付见[无需访问 GitHub 的部署](../deployment-without-github.zh-CN.md)。部署环境仍需能够访问外部模型和插件商店服务。
