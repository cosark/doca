# Doca 0.1.27

[简体中文](0.1.27.zh-CN.md)

Updates Slate to 0.4.18 and Sheet to 0.2.3. Knowledge-library document selection now uses a visible light-blue background and blue text, with no vertical marker; nested documents stay highlighted after navigation and reload.

## Editors and data

The native graph workspace includes new shapes and styles, automatic paper expansion, Ctrl/Cmd+S saving of focused drafts and corrected floating-toolbar selection. Host AI commands validate and retain native node/edge styles and canvas settings. The existing DOCX style patch is retained unchanged.

The approved new worksheet defaults are 19.8-pixel rows and 79.2-pixel columns. New documents and CRDT-appended worksheets, including historical appended worksheets, use these defaults. Original baseline fields and omitted fields, explicit per-axis dimensions, cells and original Yjs bytes are preserved. Native missing graph settings apply only to the view; explicit graph save writes new graph fields. Opening documents or regenerating previews does not migrate data. Rich-text schema 3, spreadsheet schema 6 and durable acknowledgements remain unchanged. See the [integration contract](../editor-integration.md#native-editor-upgrade--2026-10-16).

## Upgrade and rollback

From 0.1.26, stop all instances, preserve databases/files/configuration, deploy the pinned image and restart together. This release adds no core or plugin database migration. Earlier-source upgrade gates remain: installations on 0.1.25 must follow the [approved plugin uninstall/reinstall procedure](0.1.26.md#required-upgrade-from-0125).

Retain the previous deployment, lockfile and patch. Earlier editors may display different default dimensions/styles or ignore new fields; no historical-flowchart compatibility guarantee is added. Preserve all later writes when recovering; restoring old backups would discard them. No public workspace SDK changed, so no npm publication is needed.

## Verification

See [artifact audit and isolated verification](../verification/editor-package-upgrade-2026-10-16/README.md). Synthetic documents only are used for collaboration and browser tests. Existing unrelated acceptance limits from [0.1.26](0.1.26.md) remain unchanged.
