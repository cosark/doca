# Doca 0.2.3 — Fix duplicate browser tab icons

[简体中文](0.2.3.zh-CN.md)

When a title begins with an emoji followed by a space, the browser tab uses the emoji as its icon and displays the remaining title as text. This avoids showing the same icon twice. The document icon and original stored title remain intact.

Docker images are `smartdoca/doca:0.2.3` and `latest`, for Linux amd64 and arm64. The GitHub Release includes matching Web assets and the image-only deployment bundle. Existing installations should follow the [0.2.2 upgrade requirements](0.2.2.md#upgrade-and-recovery).

As requested for this release, no additional tests are run. Web assets and container images are built for publication.
