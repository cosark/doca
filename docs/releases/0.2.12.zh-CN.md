# Doca 0.2.12 — 浏览器助手切页恢复

[English](0.2.12.md)

修复浏览器助手切换网页后因抓取脚本尚未响应而报 `clipper_page_unsupported` 的问题。现在会在当前 HTTP(S) 网页的顶层框架按需加载扩展自带抓取脚本，并重试抓取一次。已有脚本正常响应时直接复用；保留真实抓取错误；重复注入不会重复注册工具栏或消息监听器。

浏览器扩展版本更新为 0.2.1，为此声明 `scripting` 权限，继续使用已有 HTTP(S) 站点访问范围。更新 Doca 后，从「浏览器助手」设置重新下载扩展、替换已解压的扩展文件，并在 Chrome / Edge 中重新加载扩展。仅更新服务端不会修复已安装的旧扩展。

真实 Chromium MV3 验证覆盖导航时脚本缺失、`document_idle` 前恢复抓取、后续网页内路由及另一标签页。模拟服务端的同一会话连续提交三条消息，无重复提交或网页刷新；未调用付费模型、未操作用户文档。见[发行验收](../verification/release-0.2.12.md)。

本补丁不新增数据库结构、持久格式转换、SDK 适配或数据迁移。继续遵循 [0.2.8 升级/恢复要求](0.2.8.zh-CN.md)与[数据库规范](../database-schema-evolution.zh-CN.md)，更换部署时保留数据库、文件、配置及部署主密钥。发布提供 GitHub 附件和 Docker Hub 镜像，不会部署生产站点。
