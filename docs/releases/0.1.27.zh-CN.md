# Doca 0.1.27

[English](0.1.27.md)

升级 Slate 至 0.4.18、Sheet 至 0.2.3。知识库左侧当前文档采用清晰浅蓝底色和蓝色文字，不显示竖线；子文档在切换、刷新和浏览器后退后保持正确高亮。

## 编辑器与数据

原生图示工作区支持新增图形／样式、纸张自动扩展、焦点草稿 Ctrl/Cmd+S 保存及浮动工具栏选择修复。宿主 AI 命令校验并保留原生节点／连线样式和画布设置。原 DOCX 样式补丁内容保留。

已同意采用新工作表默认行高 19.8／列宽 79.2 像素，新建文档和 CRDT 追加工作表（含历史追加表）采用新版默认值。不可变 baseline 原字段及缺省状态、显式行列尺寸、单元格和原 Yjs 字节保留。旧图缺省设置仅影响原生视图，明确保存图示才写入新版字段；打开文档或重绘预览不迁移数据。富文本 schema 3、表格 schema 6 和持久确认语义不变。详见[接入契约](../editor-integration.zh-CN.md#原生编辑器升级--2026-10-16)。

## 升级与回退

从 0.1.26 升级时，停止所有实例，保留数据库、文件及配置，更新固定版本镜像后统一启动。本版不新增核心或插件数据库迁移。更早版本仍须遵守原升级门禁：0.1.25 安装须先按 [0.1.26 要求正常卸载插件，更新后重装](0.1.26.zh-CN.md)。

保留旧部署、lockfile 和补丁以供恢复。旧编辑器可能显示不同默认尺寸／样式，或忽略新增字段；不增加历史流程图兼容承诺。恢复时保留后续写入，恢复旧备份会丢失其后的编辑。公开工作区 SDK 无变化，无需发布 npm。

## 验证

见[制品审计和隔离验证记录](../verification/editor-package-upgrade-2026-10-16/README.md)。协作与浏览器验证只使用合成测试文档。此前 [0.1.26](0.1.26.zh-CN.md) 的其他验收边界不变。
