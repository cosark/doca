# Doca 0.2.1 — 标题图标编辑与权限标签调整

[English](0.2.1.md)

权限状态改为浅色底、深色文字，仍以红、蓝、绿区分私有、协作和公开。主页及文档左上角标题后的标签缩小，文档列表保留独立权限列。权限计算和富文本正文标题样式保持原有行为。

编辑带 emoji 前缀的标题时，图标回到左侧选择框，文字输入框只显示标题文字。更换、移除或手动输入完整 emoji 都通过同一个标题字段保存；表单提交保留完整图标前缀。新建时先选择图标再输入文字也能保留选择。仅打开编辑并确认原值不会改写标题或原有空格。

知识库新建和改名共用同一选择框。知识库卡片与主页将名称开头的 emoji 作为图标，文字不重复显示前缀；移除后恢复原来的知识库图标。无表情名称保持原样。

富文本工具栏的表情列表包含标题选择框中的全部 24 个常用图标，同时保留原有表情并去重。两处共享同一份清单；正文和正文标题仍由原生编辑器插入普通 Unicode 文本，通过既有协作提交保存。

## 升级与恢复

更新服务端和网页到同一版本。接入正式 npm 包 Canvas 0.5.5：富文本段落菜单移除代码块入口，内联节点和候选列表样式限定在画板内。公开接口、依赖、类型声明和原生模型与 0.5.4 一致。Slate 保持 0.4.23 和原有补丁，不引入新 SDK 接口、临时压缩包、数据库结构变更、数据迁移或回填。已有标题、正文、历史、checkpoint、epoch 和待确认消息保持原样；保存时仍使用原有标题字符串和原生编辑操作。保留 0.1.32 的部署、锁文件和数据备份；回退会恢复旧界面，不能丢弃回退前的新写入。
