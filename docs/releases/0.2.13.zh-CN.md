# Doca 0.2.13 — 浏览器悬浮入口与大图收录

[English](0.2.13.md)

浏览器扩展 0.2.2 在网页右侧常驻「收录当前页面、收录选中区域、Doca 助手、设置」四个图标。拖动顶部把手可上下调整，刷新后恢复位置；收录前通过气泡确认规则及保存位置。设置在独立页面提供规则管理和后端地址。选中文字不再额外显示浮动图标。

AI 消息在对话与待发送队列中只显示一份：正在发送或已接收的消息显示为对话气泡，等待项留在队列，不再等 AI 回复后才移除。IndexedDB 恢复副本、原消息 ID、权限隔离和接收核对保持原有规则。

按用户确认的规则，新收录的静态图片超过 4 MiB 或 2500 万像素时，上传前压缩至不超过 4 MiB、最长边 4096、总像素 1600 万；保持原编码格式、PNG/WebP 透明度与 EXIF 显示方向。GIF、动态 WebP 和 APNG 不转为静态图，超过既有动画上限明确失败。已保存及已上传的图片不重新处理。原始输入读取上限 64 MiB、静态解码前上限 1 亿像素，详情见[浏览器助手](../browser-assistant.zh-CN.md)。

更新 Doca 后，请从「浏览器助手」设置重新下载扩展，替换解压目录并在 Chrome / Edge 重新加载。刷新已打开的网页以显示新工具条。仅更新服务端不会更新已安装的扩展。

本次没有数据库结构、队列格式或编辑器 SDK 变化，不迁移、删除或回填历史数据。保留原数据库、附件和浏览器存储；回退继续遵守既有队列停用约定，不把 IndexedDB 导回旧 localStorage。已压缩保存的图片仍是原有支持格式，不在回退时还原或转换。

定向测试、真实 Chromium MV3 三轮交互、390px/200% 布局、透明度及旋转图片验证见[功能验收](../verification/browser-extension-dock-2026-10-23.md)。

完整测试 3352 项通过、11 项按配置跳过。两个原生镜像验收、公开版本/latest 索引及三个 GitHub 附件均通过核对，详见[发布回执](../verification/release-0.2.13.md)。
