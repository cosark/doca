# Doca 0.2.2 — AI canvas review and document interactions

[简体中文](0.2.2.zh-CN.md)

The AI assistant can inspect a canvas through the native PNG exporter before changing a layout and after saving it. `canvas_view` supports whole-canvas, element-selection and world-coordinate region views. Its read-only receipts identify the snapshot, dimensions, scale and export warnings; authorized image bytes are supplied by the host to an isolated Chromium renderer with network access blocked. Visual review does not create assets or content/history writes.

Canvas authoring guidance now uses those views to check alignment, overlaps, overflow and readability. The build includes the renderer bundle, and the assistant shows the corresponding progress label. Document/user mention menus are positioned within the visible editor viewport. Documents whose titles start with an emoji and a space use that emoji for the browser tab icon and restore the site icon when leaving the document.

This release also removes unused internal code and shares search helpers. In-memory job leasing selects the next eligible job in one pass while preserving its ordering and lease behavior.

## Upgrade and recovery

Update server and Web together. The editor versions already released in 0.2.1 remain pinned: Canvas 0.5.5, Slate 0.4.23, Sheet 0.2.3, Markdown 0.4.3 and Slides 0.3.0-alpha.3. Core DDL, compatibility generation, persisted document formats, codec negotiation and existing historical readers are unchanged. No migration, backfill, automatic conversion or new compatibility adapter is introduced. The existing 0.2.1 upgrade and rejection rules continue to apply.

Keep databases, assets, configuration, the credential master key, original checkpoints and pending updates. Retain the 0.2.1 image and deployment files for recovery; preserve later writes before any rollback. Canvas visual review requires the existing sandboxed Chromium configuration, including the checked-in seccomp policy for containers.

## Verification

See the [release verification](../verification/release-0.2.2/README.md). Checks use synthetic accounts and isolated databases, documents, storage and container volumes. The supported image platforms are Linux amd64 and arm64. This release does not claim acceptance of every editor operation, native device or Office layout.
