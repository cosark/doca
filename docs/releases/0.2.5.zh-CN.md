# Doca 0.2.5 — MCP 服务与编辑器对接

[English](0.2.5.md)

外部 AI 可通过 Streamable HTTP 使用 Doca 助手工具和 SKILL。个人设置提供总 Switch 和多个独立服务/token，可授权全部或指定能力。公司服务每次操作须传目标 `userId`，按该用户当前权限执行。每个服务提供接入样例和可复制的一句话 AI 安装指令。原生报告、画板、PPT、表格、文件夹及分块文件传输复用已有宿主服务。详见 [MCP 接入与生命周期限制](../mcp.zh-CN.md)。

对接 Canvas 0.5.6 和 Sheet 0.2.4，历史/回收站画布预览通过下载授权回调复制图片。按已确认方案识别历史流程图包装，采用当前几何处理及椭圆/菱形连线端点显示；打开、选择和视口变化保留原模型/checkpoint 字节，显式编辑通过正常协同事务保存并支持撤销。不做批量转换、补字段或 schema 变更，仍精确要求 Canvas schema 1、Sheet schema 6。已有历史读取和恢复路径不变。详见[包比对与浏览器验收](../verification/editor-packages-2026-10-20/README.md)。

画布查看与独立图片验收按需使用已配置的识图模型；自动走线、标签排布及节点尺寸修改与原生渲染核对。收起助手侧栏会保留图片和消息。搜索结果可正常跳转并关闭搜索框，目标已打开时也会响应；无自定义图标的文档 tab 使用对应类型图标。[画布验收记录](../verification/ai-canvas-tools-2026-10-19/README.md)包含已配置模型实测及原生路径核对。

## 升级与恢复

部署前备份数据库、对象存储、部署配置及凭证主密钥，并同步更新服务端/Web。四张新 MCP 表通过最新 DDL 和 `schemaEvolution` 从空表新增，保持 `doca-2026-10-12-book-payload-storage-v1` 代际；原有内容、权限和配置保留。个人 MCP 须显式开启。按已同意方案停用未使用的旧 MCP 实现并删除 `/ai/mcp-keys` 接口，旧 token 直接拒绝、不转换。旧 `ai_mcp_keys` 表和记录仅为保全保留，运行时不读取。

[MCP 验收记录](../verification/mcp-2026-10-20/README.md)覆盖实际已发布 0.2.4 在 SQLite、PostgreSQL 17/18 创建的数据升级，核对 120 张原表摘要、重复/并发启动及拒绝时无部分写入。保留旧包和锁文件供经评审的应用恢复；回退前保全后续写入和新 MCP 记录。旧二进制不能执行新的服务授权约定，也不保证新交互的显示一致性。不提供自动降级或删除数据。更早版本仍须遵守 [0.2.2 升级要求](0.2.2.zh-CN.md#升级与恢复)。

MCP 上下文与视觉检查状态属于单实例，活动上下文须路由到同一实例；重启或过期后新建上下文并检查已保存成果。token/授权变更会使活动上下文失效。可选付费外部服务仍使用原配置与策略，MCP demo 不代表全部 provider 或所有编辑器手势均已实测。

统一发行验收见[验证记录](../verification/release-0.2.5/README.md)。镜像为 `smartdoca/doca:0.2.5` 和 `latest`，支持 Linux amd64、arm64。GitHub Release 附匹配的 Web 资源与纯镜像部署包；发布这些产物不会自动升级正在运行的站点。
