# Doca 0.2.4 — 知识册展示与批次续跑

[English](0.2.4.md)

阅读页使用紧凑、可展开的目录，补充树形连接线、文件夹/文件图标和清晰的选中状态。知识册卡片优化层级和标题换行。流程节点、连线、状态标识采用一致样式，保留紧凑总览中的可读信息，移动端节点面板增加横向滚动提示。正文流程图增加有边界的阅读容器。

完整且通过验证的模型请求可在节点中断后保留，原冻结运行继续时减少提取、规划、写作和质量验收的重复请求。否决结论、来源权限和发布必需检查继续生效，半截流响应丢弃。

此次已获同意的增补通过最新 DDL 和 `schemaEvolution` 创建空的 `knowledge_book_batch_checkpoints` 表，不改变兼容代际及历史 node/run/release 格式，不转换或回填历史数据。独立私有 v1 检查点引用复用不可变对象存储、上传日志和垃圾回收。未知版本、损坏结果、丢失对象或相同范围的模型/算法变更明确停止恢复。

部署前备份数据库及对象存储，暂停工作任务，统一更新所有执行器与垃圾回收实例，不支持新旧实例混用。当前二进制可设置 `DOCA_BOOK_BATCH_CHECKPOINTS=off` 并重启，停用批次恢复但保留记录和对象保护。已有检查点会阻止离线正文存储回滚，需另行同意保全方案。知识册永久删除沿用既有显式流程。

检查点验证包括 SQLite 211 项、PostgreSQL 17.11/18.6 各 98 项、类型检查、实际已发布 0.2.3 数据升级和真实 SIGKILL 冷进程恢复。详见[约定](../knowledge-book-generation-performance.zh-CN.md)、[检查点记录](../verification/knowledge-book-checkpoints-2026-10-19/README.md)及[发布验证](../verification/release-0.2.4/README.md)。这些结果没有测量用户反馈的线上运行耗时。

镜像为 `smartdoca/doca:0.2.4` 和 `latest`，支持 Linux amd64、arm64。GitHub Release 提供匹配的 Web 资源和无源码部署包。从更早版本升级仍需遵循 [0.2.2 升级要求](0.2.2.zh-CN.md#升级与恢复)。发布这些产物不会自动更新正在运行的站点。
