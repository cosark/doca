# Doca 0.2.6 — Page titles and document lists

[简体中文](0.2.6.zh-CN.md)

Browser tabs show the current folder, AI assistant, MCP service or workspace page name. Folder titles follow directory navigation; document tabs continue to show the document name.

Document lists replace the creation-time column with the document type: rich text, Markdown, spreadsheet, canvas or presentation. The type remains visible on narrow screens. The account menu adds an MCP services entry between Settings and Administration.

Compose pins `docker.io/smartdoca/doca:0.2.6`. The package version, quick-start commands and image-only deployment bundle use the same release number. Docker images support Linux amd64 and arm64; the GitHub Release includes matching Web assets, deployment files and a checksum.

Build, deployment bundle and image checks are recorded in the [release verification](../verification/release-0.2.6/README.md).

For existing installation requirements, read the [0.2.5 release notes](0.2.5.md#upgrade-and-recovery) before updating a running site.
