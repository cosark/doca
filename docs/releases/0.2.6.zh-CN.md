# Doca 0.2.6 — 页面标题与文档列表

[English](0.2.6.md)

浏览器标签页展示当前文件夹、AI 助手、MCP 服务和工作台页面名称。文件夹标题随目录导航更新，文档标签页继续展示文档名称。

文档列表以文档类型列替换创建时间列，区分文档、Markdown、表格、无限画板和演示文稿，窄屏也保留类型展示。头像菜单在“设置”和“管理后台”之间增加“MCP 服务”入口。

Compose 固定使用 `docker.io/smartdoca/doca:0.2.6`，项目版本、快速开始命令与纯镜像部署包采用同一版本号。Docker 镜像支持 Linux amd64、arm64，GitHub Release 附匹配的 Web 资源、部署文件与校验和。

构建、部署包与镜像检查见[发行验证记录](../verification/release-0.2.6/README.md)。

已有安装的部署条件见 [0.2.5 发行说明](0.2.5.zh-CN.md#升级与恢复)，更新运行中的站点前请先阅读。
