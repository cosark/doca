# Doca 0.2.7 — 浏览器助手与文档操作

[English](0.2.7.md)

浏览器助手支持选区工具栏、整页收录、原图归档及 AI 对话。个人设置集中管理保存目录、新建或追加策略。扩展下载包只带站点地址；使用当前浏览器的 Doca 登录状态，未登录时打开登录页，短期授权自动重新验证。插件可直接编辑服务地址，也可粘贴公开站点配置。网站退出后对应授权失效；连接可以单独或全部撤销，已保存文档保留，撤销后需手动恢复。

同时合并当前工作区的文档移动树形目录、复制目标与层级/权限修正、公司 MCP 导航入口，以及 Canvas 0.5.8 / Sheet 0.2.5 更新。画板图片采用灯箱预览，支持缩放、导航、下载和复制；编辑器包改进连接线移动、原生筛选同步及相关撤销/只读行为。验证范围见[编辑器验收](../verification/editor-packages-2026-10-21/README.md)和[浏览器助手验收](../verification/browser-clipper-login-2026-10-21/README.md)。

## 升级与恢复

现有数据库代际不变，最新 DDL 与结构协调器新增七张空的浏览器助手表，不回填历史授权或改写原文档。已用正式 0.2.6 创建的 SQLite、PostgreSQL 17/18 隔离数据验证原有 124 张表摘要保留及重复/并发启动。上线前的 v1 扩展配置和 180 天 token 停用，不作转换；此前开发记录及内容保留，更新扩展后用站点地址重新登录连接。

备份数据库、文件卷、配置和原始凭证主密钥，同步更新服务端、Web 与扩展。生产插件连接需 HTTPS；本机开发支持回环 HTTP。安装扩展需解压后通过 Chrome/Edge 开发者模式加载；未提供商店签名分发。品牌浏览器原生侧栏、真实模型供应商和真实站点登录图片矩阵仍需目标环境验收。Chrome 兼容 Chromium 自动化、模拟模型不替代这些范围。

回退需另行审阅保全方案，不能删表或直接启用旧 v1 认证来恢复运行。此前插件共享业务库等部署条件继续见 [0.2.5 说明](0.2.5.zh-CN.md#升级与恢复)。

Compose 固定镜像 `docker.io/smartdoca/doca:0.2.7`，GitHub Release 附对应 Web 资源、纯镜像部署包和校验和；Docker Hub 提供 Linux amd64 / arm64。实际构建及发布结果见[发行验证](../verification/release-0.2.7/README.md)。
