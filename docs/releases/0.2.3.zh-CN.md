# Doca 0.2.3 — 修复浏览器标签图标重复

[English](0.2.3.md)

标题以 emoji 加空格开头时，浏览器标签使用该 emoji 作为图标，标签文字只显示后面的标题，避免重复显示图标。文档内的图标和原始保存标题保持完整。

Docker 镜像为 `smartdoca/doca:0.2.3` 和 `latest`，支持 Linux amd64、arm64。GitHub Release 提供对应的 Web 资源与无源码部署包。已有部署的更新要求见 [0.2.2 发行说明](0.2.2.zh-CN.md#升级与恢复)。

按本次发布要求，不再额外运行测试；构建发布所需的 Web 资源和容器镜像。
