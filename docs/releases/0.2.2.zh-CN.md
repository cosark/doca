# Doca 0.2.2 — AI 画板视觉检查与文档交互优化

[English](0.2.2.md)

AI 助手可通过原生 PNG 导出，在修改画板布局前和保存后查看实际画面。`canvas_view` 支持整板、指定对象和世界坐标局部区域；只读回执包含快照版本、尺寸、缩放和导出警告。宿主鉴权后提供图片字节，隔离的 Chromium 渲染器禁止网络访问。视觉检查不创建资产，不写文档内容或历史。

画板创作指引使用这些画面检查对齐、遮挡、溢出与可读性。构建流程包含渲染器，助手提供对应进度提示。文档和用户引用菜单限制在可见编辑区域内。标题以 emoji 加空格开头的文档，浏览器页签同步使用该 emoji；离开文档时恢复站点图标。

本次还清理未使用的内部代码、合并搜索辅助函数，并将内存任务领取改为单次遍历，保持原有领取顺序与租约行为。

## 升级与恢复

服务端和 Web 一起更新，继续锁定已随 0.2.1 发布的编辑器版本：Canvas 0.5.5、Slate 0.4.23、Sheet 0.2.3、Markdown 0.4.3、Slides 0.3.0-alpha.3。核心 DDL、兼容代次、文档持久格式、codec 协商和现有历史读取器不变，不增加迁移、字段补写、自动转换或兼容适配。继续遵守 0.2.1 已有的升级与拒绝规则。

保留数据库、资产、配置、凭证主密钥、原始 checkpoint 和待确认更新。保留 0.2.1 镜像及部署文件用于恢复；回退前保护后续写入。画板视觉检查需要现有的 Chromium 沙箱配置，容器使用仓库提供的 seccomp 策略。
