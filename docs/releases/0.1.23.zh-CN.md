# Doca 0.1.23

[English](0.1.23.md)

本次接入 `@smartdoca/slate` 0.4.14、`@smartdoca/canvas` 0.4.3，发布插件 SDK 0.1.11，并包含工作区待发布的知识册可靠性、私有正文存储、监控和文档缓存启动改动。

富文本新增原生图形、实心箭头、可编辑手动路径与端点锚点，改进紧凑文字编辑、代码块和媒体交互。AI 创建接通新版图形和几何字段，修改图形时保留原生参数。原有 DOCX 转换补丁绑定新版实际产物。画板更新原生文字样式，公开模型、codec 和 IO 入口不变。

按已同意的方案，本次不增加旧流程图适配或自动节点转换，不保证旧流程图兼容。保留原始 checkpoint、增量、评论与待确认消息 ID；新字段按新版原生模型保存。旧编辑器不保证正确显示新图形，保留旧部署与升级前备份。该编辑器决策与下方显式知识册数据库升级分别处理。

SDK 0.1.11 增加 `monitoring.v1`、`telemetry.v1` 和管理员 Web 监控接口，依赖的契约包版本不变。知识册独立恢复通知，限制并发恢复，按需读取大正文并保持 Mermaid 预览稳定。已缓存且已授权的文档在网络发现前恢复，重连后重试原始待确认更新；需要此前在线打开、静态资源可用和浏览器存储成功，不承诺完整离线应用启动。

## 已有部署必须显式升级存储

目标数据库代际为 `doca-2026-10-12-book-payload-storage-v1`。普通启动拒绝已发布 0.1.22 的旧代际且不修改旧数据。停止全部宿主，备份 SQL、私有对象和配置，保留原主密钥、存储 ID 与部署身份。用新版镜像和原部署环境执行：

```sh
docker compose stop
docker compose pull
docker compose run --rm --no-deps doca node --import tsx apps/server/src/bootstrap/knowledge-book-storage.ts upgrade
docker compose run --rm --no-deps doca node --import tsx apps/server/src/bootstrap/knowledge-book-storage.ts upgrade --apply --hosts-stopped --manifest /data/book-upgrade-0.1.23.json
docker compose up -d
```

转换只支持准确的前代 `doca-2026-10-09-history-storage-v1`；更早代际先执行各自已审定的历史升级。新命令先把原始 JSON 字节保存到私有压缩对象并复读验证，再安装严格 SQL 引用，不猜历史默认值、不双读旧格式、不清库、不自动 VACUUM。全部宿主和 Web 构建一起更新。

中断后使用原命令与同一清单继续。回到 0.1.22 前，停止全部写入，用新版镜像执行显式存储回退并保存新的持久清单；回退也还原升级后的新成果。不能直接用旧镜像启动新库。见[存储验收与恢复](../knowledge-book-storage-verification.zh-CN.md)和[数据库演进](../database-schema-evolution.zh-CN.md)。

## 发布与验证

GitHub 标签 `v0.1.23` 包含 Web 资源、部署文件、插件 SDK 包、校验和及发行验证记录。Docker 标签为 `docker.io/smartdoca/doca:0.1.23` 与 `latest`，支持 Linux amd64、arm64。npm 发布 `@smartdoca/plugin-sdk@0.1.11`；宿主是私有 npm 项目，通过 GitHub 和 Docker Hub 分发。

发行验证附件记录最终全量测试、类型、构建、文档、原生图形 ACK/重放/撤销/checkpoint、隔离浏览器、SDK 公共消费者、PostgreSQL 17/18 与双架构镜像检查结果。保留的真实 0.1.22 镜像样本覆盖 SQLite、PostgreSQL 17/18 的字节一致存储升级与回退。全部使用合成账号和隔离数据；生产 S3 凭证、外部 AI 服务和原生移动设备不在本次验证范围。

Canvas 0.4.3 还包含用户已明确同意的视图规则：0.8 到 3 的数值文字行高按字号倍数显示，其他数值仍是像素。加载、选区、尺寸和空闲不回写模型，普通文字编辑保留原数值，仅用户显式修改行高时保存原生百分比值。不增加宿主迁移、回填或存量数据删除。浏览器验收验证 32 px 字号的 1.5 行高显示为 48 px、文字编辑后原数值保留、空闲零写入、双副本同步与重载；回退时不保证旧界面呈现。
