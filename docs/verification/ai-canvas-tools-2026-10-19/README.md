宿主只在编辑事务成功后，向独立验收提供本次实际走线命令的摘要。autoRoute/autoLabel 不持久化到 scene，原生 offset 可能是自动计算结果，不能据此误判为手写参数。摘要不覆盖以前执行，不能替代实际内容和图片检查。

画布查看和独立验收各自调用只读图片查看服务，固定快照的真实像素必须完整进入识别模型；完整观察结果还须进入执行/验收模型的请求并成功响应，才记录为已看图。空响应、截断、裁剪丢失、失败及撤权均不作为视觉通过证据。模拟模型回归同时覆盖直接视觉模型与文字模型转交。

## 可复现检查

```sh
pnpm typecheck
pnpm build
pnpm exec tsx scripts/qa-ai-canvas-routing.mts
```

静置及消息浏览器检查关闭开发热更新，固定本次编辑器会话；一次被其他任务的语言目录热更新打断的静置检查失败后，重新完整验证，仍要求零页面异常。

原生路由脚本通过已安装组件公开的 `onReady/getValue/exportFile` 检查，不调用私有组件模块、不访问数据库或外部模型。临时场景在脚本结束时清理。

本轮相关自动化测试为 15 个文件、272 项通过，覆盖画布工作流、图片证据、模型传输、工具 schema/错误恢复、文档读取和双语错误。生产构建通过；构建仍提示现有大 chunk 与 Vite 配置加载警告。

## 数据和兼容性边界

本次画布修复没有修改数据库结构、Canvas 0.5.5 依赖、codec/schema、epoch、用户文档或历史数据。已有画布不会在读取或挂载时自动修复；新命令仅执行明确请求的编辑，原对象 ID 和未请求修改的正文保留。自定义复杂走线的尺寸操作明确拒绝并整批回滚，普通连线的端点与标签随尺寸修改同步。

调查中看到的既有兼容/缺省分支包括：文件侧栏本地记忆的旧布尔值读取、画布 outline 的 `scene.children`/`children` 读取分支、原生元素缺失 name 的分类补齐，以及既有富文本/表格参数规范化与供应商协议适配。这些分支未在本次重设计、移除或迁移。没有新增旧格式转换或失败后删除数据重试的机制。

原生导出仍会报告系统字体未嵌入等警告，模型视觉检查也可能漏判或误判；记录中的通过只覆盖列出的场景，不代表所有编辑器效果或任意模型都已验证。工作区同时有其他任务的 MCP 与搜索改动，本记录不包括其数据库/功能变更。旧测试库曾因 MCP 待审结构触发启动审查，未做迁移或绕过；按用户后续要求已清理 11 个不再使用的隔离测试库，保留了检查日志和合成投影。代码尚未部署。
