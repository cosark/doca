# 编辑器键盘、协同光标和评论控件验证

验证日期：2026-10-15。使用当前安装的 `@smartdoca/slate` 0.4.15 和 `@smartdoca/sheet` 0.2.1、真实宿主服务与 Vite 开发页面，在 Chrome 中运行。全部账号和文档来自隔离的内存 SQLite；浏览器使用临时上下文，文件存储使用临时目录，没有编辑用户文档。

## 修改和原因

- 表格的原生输入框挂载在编辑器容器之外，原来的容器判断跳过了它的键盘事件。宿主现在提前注册键盘入口，由候选菜单按当前输入框接管上下键、回车、Tab 和 Escape；菜单关闭、只读、组合输入或其它输入框的按键不由候选菜单接管。
- `getNativeText()` 每次返回新包装对象。现在按稳定的编辑器句柄保留它，避免反复订阅、反复捕获草稿目标和候选菜单的更新循环。
- 文档和表格的候选项加载期间，回车不会换行或结束单元格编辑；候选加载完成后可以用键盘选中原子用户提及。文档当前版本在已加载候选项时原本可以正常使用上键和回车。
- 工作区已有服务端的昵称／公开用户 ID／内部 ID 显示规则及对应测试，本次沿用并验证，没有新增身份或旧协议适配。富文本光标竖线与名字标签分别显示：空白名字不绘制空标签，竖线保留最小高度。
- 评论与显隐按钮统一为 32 px 控件、16 px 图标和一组轻边框按钮，表格和画板共用布局，富文本的打开和收起按钮沿用同一套图标样式。原有评论和显隐操作保持原来的回调。

这次没有改变编辑器依赖版本、codec/schema、epoch、ACK/outbox、数据库结构、文档或评论存储格式，没有转换旧数据。没有修改界面文案。

主 Agent 已查看实际截图，自检了 100%、200% 和 390 px 窄屏的改动区域；局部低风险改动未派独立视觉评审，没有打分。只增加了控件的 120 ms 颜色反馈，沿用已有评论抽屉动画；没有新增操作流程或三处基本动效要求。没有删减文案。

复现脚本为 `scripts/qa-editor-interactions.mts`。执行 `pnpm exec tsx scripts/qa-editor-interactions.mts`；默认输出到 `artifacts/editor-interactions-2026-10-15`，可用 `DOCA_QA_OUTPUT` 指定目录。服务、数据库、浏览器和临时文件存储在结束时释放。
