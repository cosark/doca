# 浏览器助手待发布说明

首版支持从选区浮动工具栏和扩展弹窗收录网页语义内容，将原图归档为 Doca 附件。在个人设置集中配置目标目录、新建/追加策略、标题和 AI 整理要求；支持下载带一次性配置的扩展 ZIP、粘贴替换配置和浏览器 AI 侧栏。

连接可以单独撤销或全部撤销。撤销作废访问凭证和未使用的激活配置，并取消相关浏览器 AI 作业；已保存文档、图片和会话保留。密钥仅可调用受限浏览器接口，不代替网站、手机或 MCP 凭证。

数据库按现有结构协调器新增五张空表，不提升兼容代际、不改写现有内容或凭证。已用正式 0.2.6 的 SQLite、PostgreSQL 17/18 隔离数据验证升级；部署前备份数据库及文件存储，同步更新服务端与 Web。源码部署需包含 `apps/browser-extension`，Docker 已加入此目录。

下载 ZIP 后需解压并在 Chrome/Edge 开发者模式加载。当前没有商店发布、签名托管或 Firefox 版本。整页仅收录已加载顶层 DOM，非任意网页的完整视觉快照。实际模型供应商及品牌浏览器人工安装仍需部署环境验收。此记录不代表已发布版本或已部署服务器。
