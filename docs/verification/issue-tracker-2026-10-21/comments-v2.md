## 宿主实现

- 评论输入框保留自身键盘、剪贴板和输入法处理；冒泡不再交给相邻编辑器。富文本的宿主新增评论快捷键也排除评论输入框。
- 发送时显示转动图标和发送状态；图片读取/上传显示上传状态。失败保留文字与图片草稿，上传在原输入框卸载或文件选择取消时中止。
- 新建、回复、编辑时定位到实际输入框。发布后按服务端返回的新评论 ID 定位到消息，允许懒加载图片进入视口；不按时间或数组末项猜测消息。
- 内容评论使用实际右列占据页面宽度。区域编辑器的侧栏挂在宿主整页滚动区旁，Markdown 的正文和全文评论都在左列，评论标题不随外层页面滚走。富文本按原纸宽在正文内横滚，侧栏使用实际网格列；AI 或视口变化不会卸载已有评论草稿。
- 窄栏标题的导航及关闭操作作为一组换行；评论滚动定位保存本次挂载的源偏移，详情刷新、回复展开不再把用户滚动重置为零。
- AI 入口保留可见，在正文侧留出位置；快速滚动入口也避开评论区。
- 即使侧栏关闭也只读加载后续评论页，使 Canvas、Sheet、Slides 的后续永久锚点正常显示；显式重开侧栏仍允许重试失败页，无自动无限重试。
- 侧栏由关闭按钮或 Escape 收起。选择文件、关闭错误提示、操作 AI 不会隐式卸载评论草稿。

没有新增或修改服务器 API、数据库结构、持久格式、锚点版本、协作传输、历史、权限或数据转换。既有 Sheet 标签中的版本分支在审计中被发现，未在本次工作中修改。

## 已保留的早期失败与校准

此前实际 Canvas 0.5.11 的 Leafer `KeyEvent.DOWN` 删除处理未验证原始 DOM 事件归属。保留 Canvas 元素选中后，在评论中使用删除键，出现 seq 0 → 1 和元素删除墓碑。宿主 React 的冒泡隔离不能代替该原生路径的归属校验。Canvas 0.5.12 在子包中修复原生事件归属后，上述正式五格式回归通过。

该真实失败及早期选择器、页面滚动、原生 Canvas 命中校准均保留在 `.local/comments-v2-*`，没有删除或作为正式通过结果。此前的四格式宿主独立回归（本地产物：`comments-v2-host-browser/results.json`）和 Canvas 宿主 partial 诊断（本地产物：`comments-v2-canvas-host-only/results.json`）仍保留；partial 诊断跳过当时已知失败的原生按键，仅用于独立推进上传、侧栏及 AI 宿主交互，不能替代本轮完整五格式收据。
