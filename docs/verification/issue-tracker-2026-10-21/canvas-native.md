# Canvas native host acceptance

The dedicated script is `scripts/qa-canvas-native-2026-10-21.mts`, with disposable accounts, in-memory SQLite, a temporary file store and an isolated Vite cache on loopback port39446. It seeds only synthetic current-schema scenes through the existing collaboration exchange, then drives actual Doca UI gestures. No production document is opened and no package-internal mutation helper or product runtime bridge is added.

`tests/fixtures/issue-tracker-2026-10-21/canvas-native.json` retains the unmodified scene projection from the existing official Canvas0.5.5 fixture for the named wrapper case. Other scenarios use current native diagram, connector, container, table and note fields. This is test data, not a conversion or historical-field backfill. The test-only Vite module re-exports the installed engine's public `Leafer` object for read-only selection and live-paint geometry inspection.

Latest actual-host acceptance on 2026-10-22 uses the unpublished final boundaries candidate, SHA256 `f2aaada3c9f68e6821b0ec81cade786f0b235b85cc0012bd9b478794b9518920`. All 153 installed files matched that tarball before and after the complete 16-stage run and the separate original minimal-table supplement. Both runs passed without product or harness edits, and both browser error arrays are empty. Official npm/GitHub archive verification and production acceptance remain separate. Earlier candidate failures and calibrations below are retained as historical evidence; they are not current failures on these final candidate bytes.

The calibration corrected test gestures rather than product code: diagram labels occupy nearly the whole shape, so multi-selection clicks use a body edge outside the text bounds; container movement starts in empty interior near the border, outside its resize zone, after native Hand/Selection controls clear selection; left/top note alignment consists of two undoable commands; Escape alone does not clear selection; the dense test hovers rather than selecting a new rectangle under its floating toolbar. Export dismisses the host menu through the Selection button, because two rapid blank-canvas dismissal clicks otherwise create a new empty text element. Table offscreen coverage sends repeated capped wheel packets until its measured corner actually leaves the viewport. Mention lookup uses a token without spaces. None of these calibrations bypasses pointer hit testing, readonly guards, native commands or content-write assertions.

A separate `--stages=preflight` run checks only harness connectivity and fixture rendering; it is not a native-interaction result. All editing runs use isolated synthetic documents.
