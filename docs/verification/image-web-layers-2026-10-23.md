# Web 镜像层复用核验（2026-10-23）

本次继续优化更新镜像时的下载量。上一版五种编辑器依赖已独立分层；本次将 Web 输出拆为 CAD、字体、HTML 入口及 16 个按稳定文件名分组的代码层。Vite 的最后一段内容哈希从分组身份中排除，实际文件名、URL 和内容不改写；压缩伴随文件与原资源同组。暂存使用硬链接且保留文件及目录权限，不修改源构建。

## 实际输出与 OCI 实验

0.2.8 公开 amd64 manifest 中最后一层 Web 压缩体积为 19,683,848 字节。最终实验使用重新构建的 0.2.9 Web：483 个文件、2 个目录全部逐字节及权限核对，原构建不变；生产 Dockerfile 的全部 Web COPY 行直接参与核验，遗漏或重复任一组会失败。

隔离副本模拟真实 Vite 更新：修改入口 `assets/index-DaQ_WU0h.js` 的内容、重命名为新的八字符哈希文件，并同步更新 HTML。原始生产构建不参与修改。两份真实 OCI 制品的每个 manifest/config/layer blob 均校验 SHA256。

- 基础 Web 19 层压缩合计 19,705,336 字节；更新后 19,705,355 字节。
- 17 个层摘要完全相同，包括 CAD、字体和其余代码组；仅入口 HTML 与一个代码组改变。
- 新下载层合计 334,554 字节，其中代码组 333,139 字节、入口 1,415 字节。

该例的层下载量约减少 98.3%，只证明本例入口更新的复用边界；多代码块、依赖或基础镜像变化会增加实际下载，服务器也需保留已有层。完整镜像增加约 21KB 的 Web 分层开销，功能及文件全部保留；不把该实验宣传成每次更新固定只下载 335KB。

## 运行输入与发布范围

重新构建扩展、画布 renderer 与 Web 后，567 个运行文件、483 个 Web 文件及 9 个编辑器入口与 0.2.8 已验收镜像完全相同；仅根版本清单改为 0.2.9。五种编辑器仍为正式 npm，默认尺寸/逐文档缩放、文档内容、队列存储、数据库和沙箱均未变更。

复用验证脚本为 `scripts/qa-runtime-web-layers.mjs`。完整输出、OCI 归档和构建日志保存在忽略目录 `artifacts/verification/image-incremental-2026-10-23/`。发布前仍要求真实原生 amd64/arm64 的运行字节、鉴权、PDF、画布像素、Office 及公开 manifest 验收；新版本真实发布增量另行记录。生产站点不在本轮部署。
